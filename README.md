# holialli.github.io

Source for [holialli.github.io](https://holialli.github.io): case files and write-ups.

Built by GitHub Pages with Jekyll, no local build needed:

- `_projects/*.md`: one case file per project (front matter drives the cards).
- `_posts/`: writing. New post = new file named `YYYY-MM-DD-slug.md`.
- `_data/log.yml`: the dated log on the home page. `_data/now.yml`: the `now.txt` line.
- `assets/css/site.css`: Nord palette, light and dark.

RSS (`/feed.xml`), `sitemap.xml` and link-preview tags are generated by the jekyll-feed, jekyll-sitemap and jekyll-seo-tag plugins.
