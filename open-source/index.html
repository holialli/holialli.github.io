SageMaker compilation job output encryption check

in progress

A new Prowler check that fails when a SageMaker Neo compilation job's output isn't encrypted with a customer-managed KMS key, for issue #12604 in Prowler's AWS AI/ML security initiative.

  • collector + check
  • 15 new tests
  • needs live AWS validation

It adds compilation-job inventory to Prowler's SageMaker service, reports MANUAL rather than guessing when AWS calls fail, and treats AWS-managed alias/aws/* keys as a failure since the check is about keys you control.
