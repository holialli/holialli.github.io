Vigilance Core

Forensics tool for Windows disk images. Carves event logs, registry hives, prefetch, SRUM, USB history and more into one artifact table, flags anomalies with an Isolation Forest plus hard rules, and answers questions about the case in plain English with every claim cited to its artifact. Runs fully offline with Ollama.

  • DFIR
  • Isolation Forest
  • RAG

CloudShield

Read-only AWS posture scanner. IAM, S3 and EC2 checks mapped to CIS, sweeps every enabled region in one run, and outputs PDF and JSON. It only changes the account if you explicitly pass --remediate --allow.

  • Python
  • AWS
  • CSPM
  • CIS

aws-teardown

Finds what an AWS tutorial left running, in every region, with a monthly cost estimate and the delete commands in an order that works. Snapshot before a tutorial, diff after, and you see only what the tutorial created.
